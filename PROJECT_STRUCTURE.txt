DATABASE SCHEMA
===============

users table:
  - id (serial, primary key)
  - username (varchar, unique)
  - status (varchar) - active/disabled/expired
  - expiryDate (timestamp)
  - sublinkIds (jsonb array)
  - shortUrl (varchar unique) - df-ah-hy format
  - base64Data (text) - generated subscription
  - lastRequested (timestamp)
  - requestCount (int)
  - firebaseSyncedAt (timestamp)
  - createdAt, updatedAt (timestamps)

sublinks table:
  - id (serial, primary key)
  - name (varchar unique)
  - url (text) - subscription source
  - format (varchar) - base64/raw/json/text
  - status (varchar) - active/disabled
  - servers (jsonb array)
  - serverCount (int)
  - lastRefreshed (timestamp)
  - headers (jsonb) - from subscription
  - expireDate, quota info (optional)
  - createdAt, updatedAt (timestamps)

logs table:
  - id (serial, primary key)
  - level (varchar) - info/warning/error/success
  - category (varchar) - event type
  - message (text)
  - userId, sublinkId (optional refs)
  - metadata (jsonb)
  - createdAt (timestamp)

Plus: settings, refreshHistory, cache tables


API ENDPOINTS SUMMARY
====================

HEALTH:
  GET  /api/health

AUTHENTICATION:
  POST /api/auth/login                → JWT token

SUBSCRIPTIONS (Public):
  GET  /api/subscriptions/[userId]    → base64 or status

ADMIN (JWT Required):
  GET    /api/admin/users             → List all users
  POST   /api/admin/users             → Create user
  GET    /api/admin/sublinks          → List sublinks
  POST   /api/admin/sublinks          → Add sublink
  PATCH  /api/admin/sublinks          → Refresh all
  GET    /api/admin/logs              → View logs (paginated)
  DELETE /api/admin/logs              → Clear old logs
  GET    /api/admin/export            → Export JSON
  POST   /api/admin/export            → Import JSON

FIRST TIME SETUP
================

1. Start containers:
   $ docker-compose up -d

2. Wait for startup (~30 seconds):
   $ sleep 30

3. Access homepage:
   http://localhost:3000

4. Access admin panel:
   http://localhost:3000/dashboard-darkguard

5. Login credentials:
  Username: the ADMIN_USERNAME value configured in .env
  Password: ADMIN_PASSWORD value configured in .env

6. Add subscription source:
   → Go to Sublinks tab
   → Click "Add Sublink"
   → Paste subscription URL

7. Create user:
   → Go to Users tab
   → Click "New User"
   → Set expiry date

8. Get subscription:
   → Copy short URL from user list
   → Use: http://localhost:3000/api/subscriptions/{shortUrl}

9. Add to VPN client:
   → Hiddify, v2ray, Clash, etc.
   → Paste subscription URL
